Implement a TypeScript client-side image preprocessing utility for MedGemma 1.5 4B-IT running via LiteRT and WebGPU in the browser. The utility must transform arbitrary image inputs (PNG, JPEG, or DICOM canvas renders) into the exact tensor format required by the model's SigLIP vision backbone.Core Pipeline Requirements:Resizing & Scaling: Resize input images to a fixed $896 \times 896$ grid using offscreen HTMLCanvasElement interpolation. If the source aspect ratio is non-square, apply letterboxing padding with a zero-filled background.Color Channel Adjustment: Force output to 3-channel RGB. Drop alpha channels from RGBA inputs and replicate single-channel grayscale inputs across R, G, and B.Type Conversion & Normalization: Extract pixel arrays via ctx.getImageData(), cast values from integer [0, 255] to float32, and apply SigLIP-compatible normalization scaling.WebGPU Buffer Layout: Format the final Float32Array into a contiguous memory block matching the LiteRT model input tensor shape descriptor: [1, 896, 896, 3] (Batch, Height, Width, Channels) ready for WebGPU delegate binding.
